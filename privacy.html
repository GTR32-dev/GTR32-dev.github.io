プライバシーポリシー / Privacy Policy

最終更新 / Last updated: 2026-09-11

対象 / Scope

本ポリシーは、個人が自分専用に作成した OAuth クライアント「rclone (personal)」に適用されます。

This policy applies to "rclone (personal)", an OAuth client created by an individual for their own use only.

取得する情報 / Data accessed

本アプリは、利用者本人が許可した場合に限り、利用者本人の Google ドライブのファイルにアクセスします。

The app accesses files in the user's own Google Drive only after the user grants permission.

利用目的 / How data is used

取得したデータは、利用者本人の PC 上で rclone を使って Google ドライブをドライブとして表示・操作するためだけに使用します。

Data is used solely to display and operate the user's Google Drive as a local drive on the user's own PC via rclone.

保存と共有 / Storage and sharing

  • データは作成者が運営するサーバーには送信・保存されません。処理はすべて利用者本人の PC と Google の間で行われます。
    No data is sent to or stored on any server operated by the developer. All processing happens between the user's own PC and Google.
  • データを第三者に販売・共有・譲渡することはありません。
    Data is never sold, shared, or transferred to third parties.
  • 認証情報（トークン）は利用者本人の PC 上の rclone 設定ファイルにのみ保存されます。
    Authentication tokens are stored only in the rclone configuration file on the user's own PC.

アクセスの取り消し / Revoking access

アクセス許可は、Google アカウントの サードパーティ アクセス設定 からいつでも取り消せます。

Access can be revoked at any time from the Google Account third-party access settings.
